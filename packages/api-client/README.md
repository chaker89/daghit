# @daghit/api-client

Reusable JSON HTTP transport with timeouts, bearer authentication, typed errors, and a request-token-aware unauthorized callback. This package has no Expo, storage, navigation, or Daghit domain dependencies.

Mobile endpoint configuration and response adapters live in `apps/mobile/src/api/client.ts`. Read `docs/BACKEND_INTEGRATION.md` for the proposed server contract and open integration tasks.
